# QuickTap POS — Licence API contract

The app calls exactly three endpoints, all `POST` with a JSON body and a JSON
response, plus an `X-Api-Key` header. Base URL and key are set in
`app/build.gradle` as `LICENSE_BASE_URL` and `API_KEY`. A ready-made
self-hosted PHP implementation of this contract lives in `/php-api` at the
repo root — see `php-api/README.md` to deploy it.

## Every request

Header: `X-Api-Key: <same string as php-api/config.php's API_KEY>`

## Response shape (all endpoints)

```json
{
  "success": true,
  "status": "APPROVED",
  "message": "Licence active",
  "token": "opaque-session-token",
  "expires_at": 1767225600000
}
```

- `status` — one of `PENDING`, `APPROVED`, `REJECTED`, `BLOCKED`, `EXPIRED`
- `expires_at` — subscription end, epoch milliseconds; `0` means no expiry
- `token` — returned by `login`, replayed by `check`

## `POST {base}license_login.php`

```json
{ "email": "...", "password": "...", "device_id": "...", "device_name": "...", "app_version": "1.0" }
```

Registers the device if it is new (created as `PENDING` so it appears in the
Super Admin dashboard awaiting approval) and returns its current status.

## `POST {base}license_check.php`

```json
{ "device_id": "...", "token": "..." }
```

Called at most once every 6 hours. A device switched to `BLOCKED`, `REJECTED` or
`EXPIRED` locks the app on the next successful check. When the request fails the
app keeps working from its cached status, so the shop never stops selling
because the internet is down — but a locally expired `expires_at` locks it
immediately even offline.

## `POST {base}license_activate.php`

```json
{ "device_id": "...", "code": "ACTIVATION-CODE" }
```

Redeems an activation code generated by the Super Admin, typically returning
`APPROVED` with a new `expires_at`.

## Super Admin dashboard responsibilities

The server side must let an administrator: view active devices and login
history, approve / reject / block / unblock a device, extend a subscription, and
generate activation codes. Those are server features — none of them live in the
Android app. `/php-api` implements all of this.
